＜関数化する基準＞

・その関数だけで他でも使う可能性が高いもの

・プライベートのものなど他の関数で使えない状態のものを使えるように変換するもの

・複数の関数を使ったフローのまとめ

＜クラス化する基準＞

・同じ責務でまとめられること（一番はこれだけどこれで自分が上手く分けれる気はしてない）

・クラス名が「主語」、メソッド名が"述語の関係"にできるようにする（「アカウント」を"追加する"、「口座」に"入金する"）みたいな？

・それでも一つのクラスに入るメソッドが多い場合はより小さくクラスを作る
